Data Deletion Instructions

RamyaChobi
Last updated: 18 October 2026

RamyaChobi ওয়েবসাইটে Facebook Login বা অন্যান্য সেবার মাধ্যমে রাখা আপনার তথ্য মুছে ফেলার অনুরোধ করতে নিচের ধাপ অনুসরণ করুন।

1. Send a private request

Open the official RamyaChobi Facebook Page and send a private message headed RamyaChobi data deletion request. Include the name or email used to sign in, the relevant event if applicable, and which data you want removed. Never send your Facebook password, access token, App Secret or full payment credentials.

2. Verify the request

The studio may need to verify that the account or records belong to you before acting. Request an update through the same private conversation. This is a manual request process; submitting a message is not confirmation that deletion has finished.

3. Scope and confirmation

Ask for removal of your website authentication record, related profile information or other records you identify. The studio must assess album ownership, shared event photos, booking/payment record requirements and backups before confirming what can be deleted and any information that must be retained. Ask for the reason and applicable retention details if a record cannot be removed.

4. Remove the Facebook connection

You can also remove RamyaChobi from Facebook's Apps and Websites settings. This revokes the connection but does not automatically delete records already stored by the studio. A Facebook review or recommendation must be managed on Facebook separately.

লগআউট করা বা Facebook থেকে app সরানো মানেই স্টুডিওর সংরক্ষিত তথ্য মুছে যাওয়া নয়। অনুরোধের পর স্টুডিওর কাছ থেকে কাজ সম্পন্ন হওয়ার নিশ্চিতকরণ নিন।
